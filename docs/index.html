WLED Ambient Studio Manual

Welcome to the technical manual for WLED Ambient Studio. This project turns your standard ESP32 running WLED into a zero-latency, high-performance ambilight screen visualizer and real-time audio FFT equalizer.

🚀 Plug & Play 1-Minute Quickstart

No compilation, Node.js, or complex toolchains required. Flash the pre-built single-file bundle directly to your ESP32's LittleFS filesystem with one terminal command:

curl -F "data=@dist/index.htm;filename=/index.htm" http://10.109.101.60/upload

Or upload dist/index.htm via WLED's built-in web file manager at http://<ESP32_IP>/edit.

Default Wi-Fi Network: SSID pk / Password 00000000

🏗️ Base Pipelines Architecture: How It Works

WLED Ambient Studio operates on two zero-latency base pipelines built directly on modern browser web standards (Web Audio API & Screen Capture DisplayMedia).

Pipeline 1: Screen Ambilight Cinema Pipeline

[DisplayMedia Video Capture (60 FPS)] │ ▼ [Offscreen Canvas Downsampling (160x90)] │ ▼ [Dynamic 2.39:1 Letterbox Black-Bar Detector] ──► Auto-detects top/bottom movie bars │ ▼ [Multi-Zone Edge Extraction] ├── Left Edge (20% W, full active height) ├── Top Edge (full W, 20% H) └── Right Edge (20% W, full active height) │ ▼ [16-Bucket HSV Dominant Chroma Filter] ──────► Isolates vivid scene colors, ignores grey │ ▼ [Proportional Section Division (e.g. 3-4-2)] ──► Maps LEDs: 20 Left • 27 Top • 13 Right │ ▼ [LERP Smoothing Filter (α = 0.35)] ──────────► Cinematic organic color transitions │ ▼ [Compact WLED WebSocket Range Payload] ───────► seg.i: [0, 20, colL, 20, 47, colT, 47, 60, colR] │ ▼ [ESP32 WS2812B Hardware Output] ─────────────► Real-time 60 FPS playback (<15ms latency)

Pipeline 2: Audio FFT Spectrum Pipeline

[Audio Source (Mic / System Audio / Synthwave)] │ ▼ [Web Audio API AudioContext + AnalyserNode (256-point FFT)] │ ▼ [3-Band Frequency Energy Integration] ├── Bass & Sub-bass (20Hz - 250Hz, Bins 1-6) ├── Midrange (250Hz - 4kHz, Bins 7-24) └── Treble (4kHz - 16kHz, Bins 25-60) │ ▼ [Beat Transient Peak Detector (Energy History Buffer)] ──► Triggers pulses & BPM tracking │ ▼ [12 Dynamic Algorithms + 14 Color Palettes] ────────────► Generates per-LED RGB arrays │ ▼ [Direct WebSocket Stream to ESP32] ──────────────────────► Instant hardware visualization

Power Sizing Rule: WS2812B LEDs consume up to 60mA each at full white brightness. For 60 LEDs, ensure your power supply provides at least 60 * 0.06A = 3.6A.

🖥️ 3-Zone Monitor Setup & Section Division (3-4-2)

Standard ambilight tools assume a 4-sided TV frame. For desktop monitors, the stand blocks the bottom edge. WLED Ambient Studio introduces dedicated 3-Side Monitor geometry and proportional section division.

Built-in Division Presets (for 60 LEDs):

Ratio / Preset Left Edge Top Edge Right Edge Application
3 : 4 : 2 20 LEDs (33%) 27 LEDs (45%) 13 LEDs (22%) User Custom / Asymmetric Wiring
1 : 2 : 1 15 LEDs (25%) 30 LEDs (50%) 15 LEDs (25%) Standard 16:9 Desktop Monitors (27", 32")
1 : 1 : 1 20 LEDs (33%) 20 LEDs (33%) 20 LEDs (33%) Equal Thirds / Square / Portrait Displays
1 : 3 : 1 12 LEDs (20%) 36 LEDs (60%) 12 LEDs (20%) 21:9 Ultrawide Curved Monitors (34", 38")
3 : 5 : 3 16 LEDs (27%) 28 LEDs (46%) 16 LEDs (27%) 32:9 Super Ultrawide Displays (49")

Strip Wiring Direction:

Choose between Bottom-Left ➔ Top ➔ Right (Clockwise) or Bottom-Right ➔ Top ➔ Left (Counter-Clockwise) from the dropdown menu to match how your strip is physically adhered.

❓ Troubleshooting & FAQs

Q: Why is screen sync black on Netflix / Amazon Prime?

Hardware-accelerated Widevine DRM in Google Chrome obscures video frames for privacy. To sync ambilight with DRM content, go to chrome://settings/system and toggle off "Use graphics acceleration when available", or view video in VLC, Firefox, or media players.

Q: How does the engine achieve 60 FPS without crashing the ESP32?

WLED Ambient Studio compiles all edge colors into a single compact range packet (seg.i = [start1, stop1, col1, start2, stop2, col2]). This is only ~70 bytes per WebSocket frame, keeping CPU utilization on the ESP32 under 8%.

Q: Do I need an external microphone connected to the ESP32 for music sync?

No! The Web Audio API runs the 256-point Fast Fourier Transform (FFT) directly in your browser on your computer or phone. Your ESP32 only receives the clean, calculated per-LED color data.
